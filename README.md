## 🏋️ Proyecto Estrella — `BeniMax` (TFG)

**BeniMax** no es un ejercicio de clase — es una app nativa de Android (Java) construida de principio a fin, pensada para resolver un problema real: **entrenar con datos, no con intuición.**

Une dos cosas que me apasionan: la hipertrofia y el código limpio.

| Módulo | Qué demuestra |
|---|---|
| 🗂️ **Persistencia de datos** | Modelo de datos propio para historial de entrenamientos, series y cargas — sin perder integridad entre sesiones |
| 🎯 **RIR Tracking** | Lógica de negocio para registrar Repeticiones en Reserva y calcular progresión real, no solo peso levantado |
| 📊 **Progresión medida** | Algoritmos que traducen entrenos sueltos en tendencias accionables para el usuario |
| 📱 **UI/UX nativo** | Interfaz pensada para usarse *en el gimnasio, entre series* — rápida, sin fricción, sin distracciones |

> El objetivo no era "que funcione". Era que un usuario real lo usara la semana que viene y volviera a usarlo la semana siguiente.
